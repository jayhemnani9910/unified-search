Nothing is tagged yet. Work so far, from the git history (December 2025 to now):

### Added
- Whitepaper, "The Unified Theory of Autonomous Search", with 10 references.
- Python Digital Lab simulator with five strategies (random walk, Levy flight, gradient ascent, surge-cast, swarm stigmergy) and static or turbulent signal.
- Leaderboard runner with optional bar-chart plots.
- GitHub Pages site with an in-browser simulator, charts, CSV download and a live agent animation.
- MIT license.
- CI: ruff, a one-trial simulator smoke run, JS syntax check, and a check that `site/` matches `docs/`.
- Demo GIF, CONTRIBUTING.md, issue and PR templates.

### Changed
- README rewritten.
- Sorted imports and builtin generics in `sim/`. The sim scripts are no longer marked executable.
